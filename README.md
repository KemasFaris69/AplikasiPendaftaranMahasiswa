Nama: Kemas Faris Rahadiansyah

Studi kasus: aplikasi pendaftaran mahasiswa baru. Struktur HTML ini disiapkan sebagai dasar pengembangan proyek fullstack pada tugas berikutnya.

- `index.html`: daftar contoh calon mahasiswa dalam tabel.
- `pendaftaran.html`: formulir pendaftaran mahasiswa.
- `detail-pendaftaran.html`: detail contoh pendaftaran PMB-001.
- `assets/pendaftaran-mahasiswa.svg`: ilustrasi lokal pada halaman detail.
- `docs/screenshots/`: tangkapan layar tiap halaman di browser.

Buka `index.html` di browser, lalu gunakan navigasi untuk mengakses halaman lainnya. Semua halaman menggunakan HTML murni tanpa CSS, JavaScript, maupun framework. Data pendaftar bersifat fiktif; formulir belum menyimpan data karena tidak ada backend. Jangan mengisi data pribadi asli pada contoh ini.
